Reflection

Midterms

What I Learned

I learned how to make a simple functional search engine, list management applications, and how to integrate third-party APIs like Weatherstack into an Angular application.

Challenges I Encountered

Integrating third-party APIs was quite challenging as I had to understand how to make HTTP requests and handle responses within the Angular framework. Pushing projects with APIs to GitHub Pages was also tricky since I had to configure the application properly to ensure that the API calls worked correctly in a deployed environment.

Conclusion

The midterm projects were a great learning experience that helped me understand the practical applications of Angular and how to work with external APIs.
